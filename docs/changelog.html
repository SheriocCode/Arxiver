v0.10.0（2026-10-15）

  • 运行状态（新）：左侧栏新增「运行状态」页——已运行时长 / 进程数 / 合计内存 / 合计 CPU、内存与 CPU 趋势图 （每 2 秒采样、保留约 3 分钟，离开本页仍在后台继续）、可分组与排序的进程列表（名称 / 类型 / PID / 内存 / CPU / 迷你趋势）、 可切换「工作集 / 提交大小」两种口径；底部单列主进程的子进程（Python 引擎、本地模型服务 llama-server：PID / 内存 / 端口 / 正在翻的文件） 与翻译任务进度；可暂停采样、打开日志文件，并 一键导出诊断报告（进程快照 + 环境信息 + 最近日志）。
  • 进度与耗时：阅读器进度条改为 按页 计算并显示百分比与转圈；每次翻译的分段耗时（引擎就绪 / 版面模型加载 / 版面分析 / 全流程） 写进「日志 → 系统运行日志」；翻译预览改为 每翻完一页 就刷新，更跟手（保留 1 秒写入下限）。
  • 日志视图：翻译 / AI 对话 / 系统运行三类常驻，切换不再闪「暂无记录」；修复 AI 对话日志点哪条都还停在第一条。
  • AI 助手：点 停止不再清空内容——保留已生成部分并标为「已暂停生成」，可 「重新编辑问题」 把问题回填输入框；消息去掉头像、收紧布局。
  • 阅读与导航：从阅读视图点导航或点侧栏分类 / 标签会回到文库视图，不再被阅读器盖住；Esc 只关弹层 / 整页视图，不误关文章； 焦点描边只跟随键盘操作；详情面板「所有标签」改为对当前文献添加 / 移除。
  • 修复：同一篇论文导入两次时翻译日志出现两条重复记录；个别 PDF 在 字体子集化 一步导致整任务失败（现改为尽力而为，失败不中断翻译）； 设置里的 API Key 与联网搜索项补上 DeepSeek / Tavily / 博查官网链接。
  • 引擎更新至 0.3.1：字体子集化容错、预览刷新节奏、分段耗时埋点。

v0.9.0（2026-10-14）

  • Arxiver 助手联网检索：可搜索文库外的论文与资料，结果以卡片列出（标题 / 站点 / 年份 / 摘要片段 / 链接）， 带 arXiv 编号或 DOI 的条目可一键导入文库；回答里用 卡片 N 引用来源，点击滚动并高亮对应卡片。 搜索服务商可选 Tavily 或 博查（Bocha），两家 Key 各自保存、随时切换，检索范围可选 学术优先 / 全网。
  • 读正文：助手在给结论前会把最相关的网页 / PDF 正文读进来（优先服务端抽取，取不到就本机抓取）， 对话里显示「已读正文 · 站点 · 字数」并可打开原链接。
  • 助手更多写作操作：导入外部论文（arXiv 编号 / DOI / 链接）、增删笔记、重命名或删除分类、把文献移出分类等， 全部先弹确认卡片；长任务（搜索 / 读正文 / 导入下载）显示当前阶段与已用时间； 分类 / 标签名对不上时助手会自己查候选再确认，不再让你核对拼写。
  • 日志视图重做：左侧「日志」分 翻译日志 / AI 对话日志 / 系统运行日志 三类——每次翻译的状态与耗时、 会话的完整工具调用步骤（参数 / 结果 / 计时 / Token）、分级运行记录（含联网检索与正文读取）。
  • 文库分类与标签管理：侧栏拖拽分类可调整顺序与层级（拖到分类上成为子分类），右键可新建 / 重命名 / 删除； 标签右键可重命名 / 删除 / 调色（预设色 + 色轮）。删除分类只删分类本身，删除标签会从所有文献上移除，都不会删除文献。
  • 导入更省事：PDF 可直接拖到文献列表导入；「新建文献」支持粘贴 arXiv 链接 / 编号 / DOI 并自动取回元信息， 入库后从 PDF 补全标题 / 作者 / 年份 / 来源；文献也能直接拖到侧栏分类里归类；列表上方新增搜索框。
  • 阅读器：打开默认「原文 + 单页」；工具栏新增块框按钮，可直接在阅读界面开关段落块框（无译文时不可用）， 块框改为点击钉住、面板贴着块框并跟随滚动；导出改到「翻译」下拉里的「导出译文文件…」，关闭文档用标签栏的 ×。
  • 更新提示：顶栏显示「有新的更新 / 正在下载更新 N% / 更新已就绪」，点击直达设置； 启动时静默检查更新，「关于」里可下载 / 重启安装，并直接看到该版本的更新内容。
  • 修复：切换视图后块框消失；更换界面背景不生效；查看译文时块框默认值不对；设置项滑块样式异常； 助手面板中间结果过长导致横向滚动、输入框首次打开点不进去；自定义安装目录时给出最终位置提示（并允许直接选驱动器根目录）。
  • 列表与侧栏的选中态改为中性灰，不再用青绿色块填充。
  • 引擎更新至 0.3.0：新增 engine/pdfmeta.py，探测 PDF 自带元信息与首页里的 arXiv 编号 / DOI，供导入时自动补全。
  • ⚠️ 升级须知：联网搜索默认关闭，需在「设置 → AI 助手 → 联网搜索」开启并填入当前服务商的 API Key； 只发送检索式与要读取的网址，不上传本地文献内容（Key 以明文存于本机 config.json）。

v0.8.0（2026-10-12）

  • 多标签页阅读器：每个文档独立渲染，切换标签不再重建 PDF、无闪烁；翻译在后台继续，任务按文档独立排队与取消。
  • 文献列表重做：标签改为可配色的彩色圆点（10 个预设 + 任意色轮取色，超出显示 +N）；标题单行省略，不再换行。
  • 无书签 PDF 自动生成目录：离线启发式按字号 / 加粗 / 编号 / 章节名识别标题，面板标注「自动生成」，结果缓存。
  • 启动动画与自定义界面背景：开屏动画可开关；界面背景支持图片 / 视频（视频静音循环），并提供不透明度滑块。
  • 块框显示拆分：分别控制「翻译时」与「查看译文时」是否标出文本块。
  • 修复：目录点击错跳 / 多条目同时高亮 / 点击无反应；启动瞬间「整屏灰色 + 左上角黑块」；界面设置偶发丢失（改存本地 ui-settings.json，同步落盘）。
  • ⚠️ 升级须知：界面设置不再读取旧的浏览器存储，升级后外观 / 启动选项会回到默认值，请重新设置一次；文库、笔记、已有译文与标签不受影响。

v0.7.0（2026-10-11）

  • 本地离线翻译：翻译改由随包分发的 HY-MT 翻译模型（llama.cpp）在本机完成，安装即用、无需 API Key； 有 NVIDIA 显卡走 GPU，无独显 / 驱动不匹配时自动回退 CPU。
  • 翻译与会话分离：AI 助手使用独立配置的在线接口，与翻译互不影响，也更省 API 费用。
  • 版面识别提速：改用 DirectML 显卡加速（约 6–10 倍），无 DX12 显卡自动回退 CPU。
  • 预览更流畅：修复翻译过程中预览 PDF 的重复重建，长文档整体更快。
  • ⚠️ 升级须知：配置项已重命名（openai_* → translate_* / chat_*），升级后请在「设置 → AI 助手」 重新填写接口；文库、笔记与已有译文保留。

桌面版（Electron）

以 Electron 桌面应用取代原「浏览器扩展 + 本机服务 + 托盘启动器」组合。

  • 桌面文献库：导入、分类、标签、回收站、阅读历史与检索。
  • 双语对照阅读器：原文 / 对照 / 译文三视图，单页 / 双页、缩放、目录大纲、缩略图、页面主题。
  • 内嵌引擎（本地离线翻译）：随应用分发 HY-MT 翻译模型（llama.cpp），默认在本机离线翻译；有 N 卡走 GPU，无独显自动回退 CPU。AI 助手使用独立配置的在线接口。
  • 段落块框与引用：悬停显示「原文 → 译文」；引用预览目标页、点击跳转。
  • Arxiver 助手：基于当前文章与整库的对话式检索、可点击引用、@ 引用已打开文献、选中文本提问； 标签 / 元数据等写操作经人机协作确认；会话持久化与历史。
  • 自动更新：electron-builder（NSIS）+ electron-updater 差量更新，未变的大文件不重复下载。
